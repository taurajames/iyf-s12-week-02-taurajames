
# DevTools Exploration

## Introduction

Browser Developer Tools help developers inspect webpages, identify errors, test layouts and understand how HTML, CSS and JavaScript work together.

For this exercise, I explored the Developer Tools in my browser while working on my portfolio website.

## 1. Inspecting HTML

I used the Elements panel to inspect the structure of my webpage.

I explored elements such as:

- `header`
- `nav`
- `main`
- `section`
- `footer`

This helped me understand how HTML elements are organised on a webpage.

## 2. Inspecting CSS

I explored the Styles panel to see how CSS rules affect the appearance of webpage elements.

I looked at properties such as:

- `color`
- `background-color`
- `font-family`
- `margin`
- `padding`

This helped me understand how styling changes affect the layout and appearance of my portfolio.

## 3. Testing Responsive Design

I explored the device toolbar to see how a webpage can appear on different screen sizes.

Responsive testing is important because visitors may access a website using mobile phones, tablets or computers.

## 4. Checking for Errors

I explored the Console panel to learn where browser errors and JavaScript messages appear.

The Console can help developers identify and troubleshoot problems in their code.

## 5. What I Learned

This exercise helped me understand that Developer Tools are useful for testing and improving websites.

I learned that I can inspect HTML, experiment with CSS, test responsive layouts and investigate browser errors without directly changing my source files.

## Conclusion

Developer Tools are an important part of web development because they help developers examine, test and debug webpages.

I will continue using these tools as I improve my portfolio and learn more about accessible web development.
