
# Accessibility Report

## Introduction

Accessibility means designing websites so that people with different abilities can use and understand them.

For this project, I am checking my portfolio for accessibility issues and documenting improvements.

## 1. Accessibility Checks

I will check the following areas:

- **Page structure:** Use semantic HTML elements such as `header`, `nav`, `main`, and `footer`.
- **Headings:** Organise content with a logical heading hierarchy.
- **Navigation:** Provide consistent navigation links across the four main pages.
- **Forms:** Ensure each form field has a matching label and required fields are identified.
- **Keyboard access:** Check that links and form controls can be reached using the keyboard.
- **Focus visibility:** Ensure keyboard focus is clearly visible.
- **Responsive design:** Check the layout at different screen sizes.
- **Images:** Provide meaningful alternative text for informative images.
